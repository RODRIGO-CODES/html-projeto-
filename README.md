# html-projeto-O projeto Irmãos Cell é um site desenvolvido utilizando HTML5, com o objetivo de aplicar os conceitos de estrutura semântica, formulários e multimídia.
A loja Irmãos Cell atua na compra de aparelhos eletrônicos danificados, na venda de celulares novos e seminovos, e na oferta de serviços de assistência técnica.
